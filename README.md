# GAME LIST — 내 Switch 게임 라이브러리

Nintendo Switch / Switch2 소장 게임 509개를 관리하는 개인용 PWA 앱입니다.
서버 없이 정적 파일만으로 동작하며, 모바일에서는 앱처럼(설치·오프라인·체크/즐겨찾기) 사용할 수 있습니다.

---

## 1. 로컬에서 바로 실행하기

별도 빌드 과정이 필요 없습니다. 폴더 안의 `index.html`을 열면 바로 동작합니다.

> ⚠️ **중요 — 모바일에서 `index.html`을 그냥 더블탭/직접 열면 스타일이 깨져 보일 수 있습니다.**
> 이 앱은 `css/style.css`, `js/app.js`, `js/data.js`를 같은 폴더의 별도 파일로 불러오는 구조입니다.
> 그런데 많은 모바일 브라우저(특히 카카오톡 인앱 브라우저, 일부 파일관리 앱의 "빠른보기")는
> `file://`로 연 HTML이 같은 폴더의 다른 파일을 불러오는 것을 보안상 차단합니다.
> 이 경우 CSS/JS가 전혀 적용되지 않아 꾸밈없는 뼈대 HTML만 보이게 됩니다.
>
> **해결 방법**
> - PC(데스크톱)의 일반 브라우저(Chrome, Edge 등)에서 여는 것은 대부분 문제없습니다.
> - 모바일에서 빠르게 확인만 하고 싶다면, 아래 2번(정적 배포) 방법으로 실제 웹 주소에
>   올려서 접속하거나, 로컬 서버(`python3 -m http.server`)로 열어주세요.
> - 또는 완전히 하나로 합쳐진 단일 파일 미리보기 버전을 함께 요청하시면 외부 파일 호출
>   없이 바로 열리는 버전을 드릴 수 있습니다. (단, PWA 설치/오프라인 기능은 빠진 테스트용입니다.)

- 가장 간단한 방법: `index.html`을 더블클릭해서 PC 브라우저로 열기
  (단, 이 경우에도 PWA 설치와 오프라인 캐싱(Service Worker)은
  브라우저 보안 정책상 `file://` 환경에서 동작하지 않습니다.)
- 완전한 PWA 기능(설치, 오프라인)까지 확인하려면 아주 가벼운 로컬 서버로 열어주세요.
  예: 이 폴더에서 터미널을 열고
  ```
  python3 -m http.server 8080
  ```
  그다음 브라우저에서 `http://localhost:8080` 접속

## 2. 앱 설치 방법 (홈 화면에 추가)

1. 위 방법으로 `https://` 또는 `http://localhost` 주소로 접속합니다.
   (정적 호스팅에 올린 뒤 접속해도 동일합니다.)
2. **Android(Chrome)**: 상단 앱바의 설치 아이콘을 누르거나, 브라우저 메뉴 → "앱 설치" 선택
3. **iPhone(Safari)**: 공유 버튼 → "홈 화면에 추가"
4. 홈 화면 아이콘으로 실행하면 브라우저 주소창 없이 독립된 앱처럼 열립니다.

## 3. 정적 웹 배포 방법

이 폴더 전체를 다음과 같은 정적 호스팅 서비스에 그대로 업로드하면 됩니다.
빌드 과정이 없으므로 파일을 그대로 올리기만 하면 됩니다.

- GitHub Pages
- Netlify / Vercel (정적 사이트로 배포)
- Cloudflare Pages
- 개인 웹서버 (Nginx, Apache 등)

배포 후에는 HTTPS 주소로 접속해야 PWA 설치와 오프라인 캐싱이 정상 동작합니다.

## 4. 새로운 게임 목록으로 업데이트하는 방법

목록에 게임이 추가되거나 변경되면, **디자인·코드는 그대로 두고 데이터만 교체**하면 됩니다.

1. 최신 Excel 파일을 준비합니다. (`리스트` 시트, B58행부터 시작하는
   `순번 / 타이틀 / 구분 / 형태 / 엔딩 / 비고` 표 구조를 따라야 합니다.)
2. 터미널에서 다음 명령을 실행합니다.
   ```
   pip install openpyxl
   python3 scripts/xlsx_to_json.py 새파일.xlsx
   ```
3. `js/data.js` 파일이 자동으로 갱신됩니다.
4. 브라우저에서 새로고침하면 새 목록이 반영됩니다.

> **번호가 밀려도 기록은 안전합니다.**
> 클리어 여부와 즐겨찾기는 게임 번호가 아니라, 카테고리 + 제목으로 만들어진
> 고유 id를 기준으로 저장됩니다. 따라서 중간에 새 게임이 추가되어 번호가
> 한 칸씩 밀리더라도, 기존 게임의 클리어/즐겨찾기 기록은 그대로 유지됩니다.
> (단, 기존 게임의 **제목 자체**가 바뀌면 새로운 게임으로 인식되어 id가 새로
> 생성되니 주의해 주세요.)

## 5. 백업 / 복원 방법

앱 내부의 **카테고리 탭 → 데이터 관리**(모바일) 또는 상단 버튼(PC)에서 사용할 수 있습니다.

- **백업**: 현재 클리어 기록 · 즐겨찾기 · 마지막 화면 설정을 JSON 파일로 내려받습니다.
- **복원**: 백업해둔 JSON 파일을 선택하면 그 시점 상태로 되돌립니다.
- **초기화**: 클리어 기록과 즐겨찾기를 모두 지웁니다. (되돌릴 수 없으니 주의)

기기를 바꾸거나 브라우저 데이터를 지우기 전에는 꼭 백업 파일을 받아두는 것을 권장합니다.
(모든 기록은 기기의 브라우저 `localStorage`에만 저장되며, 서버로 전송되지 않습니다.)

## 6. 폴더 구조

```
game-library-app/
├─ index.html          앱 진입점 (모바일/PC 레이아웃 모두 포함)
├─ manifest.json        PWA 설정 (아이콘, standalone 모드 등)
├─ sw.js                 Service Worker (오프라인 캐싱)
├─ css/
│  └─ style.css          전체 스타일
├─ js/
│  ├─ data.js             게임 데이터 (CATEGORIES, GAMES) — Excel에서 자동 생성됨
│  └─ app.js               앱 로직 (렌더링, 상태 저장, 백업/복원, PWA)
├─ icons/                 앱 아이콘
├─ scripts/
│  └─ xlsx_to_json.py      Excel → js/data.js 변환 스크립트
└─ README.md
```

## 7. 주요 기능 요약

- 전체 목록 / 카테고리(15종) / 즐겨찾기 3개 탭 (모바일 하단 내비게이션)
- **최초 실행 시, 원본 Excel의 "엔딩" 완료 표시가 자동으로 클리어 체크에 반영됩니다.**
  (이후에는 사용자가 직접 체크/해제한 기록이 항상 우선하며, 다시 자동으로 덮어쓰지 않습니다.)
- 실시간 검색 (한글/영문/숫자, 부분 일치)
- 클리어 여부 체크 — 탭 즉시 반영, 새로고침해도 유지
- 즐겨찾기 — 별표로 추가/해제
- 정렬 (번호순 / 가나다순), 카테고리별·클리어 상태별 필터 (전체 목록 화면 상단에서 전체/미클리어/클리어 전환)
- 상단 대시보드 카드에서 진행률과 클리어/미클리어 개수를 한눈에 확인
- PC 화면에서는 15개 카테고리를 한 화면에 표(그리드)로 볼 수 있는 전용 레이아웃
- PWA: 홈 화면 설치, 오프라인 사용, standalone 실행, 노치/제스처 영역(Safe Area) 대응
- 데이터 백업 / 복원(JSON), 초기화
